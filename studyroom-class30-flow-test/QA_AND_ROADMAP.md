# STUDY ROOM — 기능 우선 개선: 자유 이동 → 착석 → 어깨너머 카메라

> 버전: `studyroom-class30-flow-test/`. 기존 `studyroom-class30-wasd-test/`와 운영판은 변경하지 않음.
>
> 실행 주소: https://gtmc-history.github.io/studyroom-class30-flow-test/

## 목표 기능과 현재 구현

1. **WASD/방향키 자유 이동:** 기존 로컬 방문자 캐릭터를 유지. 좌석·서버 공부 시간은 이 단계에서 사용하지 않음.
2. **좌석 선택:** 책상 근처 E키 또는 화면의 30석 목록 사용. 확인 창에서 별명·공부 과목·모드 설정 후 확정.
3. **현재 위치 보존:** 예약 직전에 로컬 캐릭터의 (x,z)를 저장함. 서버 착석 성공 시 해당 위치에서 새 좌석 캐릭터가 출발하며 기존의 입구 텔레포트 제거.
4. **장애물 회피:** 격자 간격 약 0.17, 4방향 연결 BFS, 선형 보간 시 장애물 충돌 검사 및 가시성 기반 경로 단축. 기존 책상·의자 AABB + 캐릭터 반경 약 0.26. 목표 책상 **뒤쪽 접근 지점**까지 충돌 없는 길을 구한 다음, 마지막 짧은 구간만 의자 착석 애니메이션으로 처리. 길이 없으면 서버 예약 **전에** 안내하고 중단.
5. **자동 걷기·착석 연결:** 새로운 좌석 캐릭터가 출발점부터 목표 의자까지 걷고, 도착하면 `onSeatArrived30`으로 공부 기록 시작. 기존 `sr6_state`, 기록 이벤트 및 사용권한 방식은 변경하지 않음. 화면 회전으로 레이아웃이 바뀌면 재탐색 후 이어 가며, 새 구조에서 경로가 불가능할 경우 안전한 입구 경로로 복귀.
6. **책상 어깨너머 시점:** 30석 학급형에서 착석 후 카메라가 캐릭터 뒤(z가 의자보다 작은 방향)에 위치하고, 좌/우 어깨에서 책상 위를 바라보도록 설정. 캐릭터 본인과 책상을 함께 볼 수 있음. 휴식 시 기존 창밖 보기로 전환하고 다시 공부하면 어깨너머 시점으로 돌아옴.
7. **기존 기능 유지:** 30석 인덱스 0~29, 1인석 12 + 2인 공유석 18, 인증, Supabase RPC, 누적 기록, 학교별 방, 기존 바다 풍경 등 변경하지 않음.

## 수행한 모의 검증 (실제 Chrome 렌더링 아님)

- PC 1200×800: 입구·통로의 여러 위치 × 30좌석 **540건**, 충돌 없는 경로 540건.
- 모바일 크기 390×844: 여러 통로 위치 × 30좌석 **210건**, 충돌 없는 경로 210건.
- 책상 뒤에서 출발하는 추가 접근 경로 PC **70건**, 모바일 **78건** 모두 통과.
- 출발점 연결 모의 실행: PC/모바일 각각 입구 출발과 책상 앞 출발을 시험하여 **실제 시작 좌표 유지, 마지막 좌표는 선택 의자**, 도착 전 상태 `walk` 확인.
- 어깨너머 카메라: PC/모바일 각 0·5·16·29번 좌석 확인. 모두 카메라가 캐릭터보다 뒤, 목표 시선은 책상 쪽, 카메라는 도서관 경계 안쪽.
- GitHub 원본과 분리된 파일로 반영, 전체 인라인 JS 문법 검사 통과.

## 아직 검증되지 않음

- 실제 headless Chrome/WebGL 이미지·비디오, 앉은 캐릭터가 책상과 자연스럽게 함께 보이는지에 대한 시각 검증
- 실제 Supabase에서 E키 → 착석 → 공부 기록 → 휴식 → 종료 → 새로고침 회귀 테스트
- 30명 동시 접속 및 다른 사용자 캐릭터/Realtime 안정성
- 320px 소형 모바일, 저사양 크롬북·Android·iPhone의 FPS와 객체 수
- 카메라의 벽·책장·조명에 대한 정밀 가림 방지

## 다음 기능 개발 우선순위 (디자인 수정 전)

1. **카메라 가림 방지:** 3인칭 따라가기·어깨너머 시점에서 벽과 큰 책장이 얼굴/책상 사이에 끼는 문제를 실측하고 카메라 안전 거리를 자동 조절
2. **시점과 이동 방향 통일:** 드래그로 카메라를 회전했을 때 W가 현재 시점의 앞으로 이동하도록 만드는 옵션 검토
3. **모바일 가상 조이스틱:** 작은 화면의 엄지 이동 패드, 별도 카메라 조작, E 좌석 상호작용
4. **자유 이동 중 안내 개선:** 근처 빈 좌석 하이라이트 및 E키 표시, 이미 사용 중인 좌석과 빈 좌석 구별
5. **학급형 안정성:** 30명 실제 동시 접속, 저장 신뢰성, 학교 Realtime 접근 제어, 미성년자 개인정보 운영 안내

**이후 디자인 단계:** 4면 도서관 건축적 완성도, 테마별 실감형 창밖 풍경, 책장/책상 모델 상세화, 조명 및 성능 최적화. 기능을 안정화하기 전 별도 외형 확장 없음.

## 클로드 독립 검수 권장

1. 이전 WASD 시험판 vs Flow 시험판을 같은 30석, 같은 Chrome viewport에서 실행.
2. 방문자 캐릭터를 책상 가까이 WASD 이동 → E → 착석 확정 → **입구로 되돌아가지 않는지** 영상으로 기록.
3. 0, 5, 16, 29번 좌석에서 착석 완료 후 카메라가 **캐릭터 등 뒤**에 있고 책상이 앞에 보이는지 스크린샷 비교.
4. 반대편 좌석까지 이동 시 통로를 우회하는지, 2인 책상을 관통하지 않는지 검증.
5. 이동 도중 회전, 취소, 세션 저장 오류, 휴식·재개·종료, 텍스처/지오메트리 누수 검증.
6. 위 테스트와 운영판/기존 시험판을 혼동하지 말 것. 실제 서버 테스트는 별도 승인 하에 최소 범위로 진행.

검수 판정은 **코드/모의 기능 통과**, **실기기/서버 미검증으로 학생 공개 보류**.
